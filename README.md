# 장애인 고용 지원 웹페이지 디자인

한국장애인고용공단을 주제로 제작한 비공식 웹페이지 디자인 시안입니다. 공단이 운영하거나 승인한 사이트가 아닙니다.

## 사용하기

`index.html`을 브라우저에서 열면 됩니다. 별도의 설치나 빌드가 필요하지 않습니다.

- 개인·기업 지원 메뉴 전환
- 모바일 대응 레이아웃
- 글자 확대와 키보드 탐색
- 공식 서비스 사이트 연결

실제 상담 접수, 회원가입, 채용 데이터 제공 기능은 포함하지 않으며, 관련 서비스는 공식 누리집으로 연결됩니다.

## GitHub Pages

저장소 Settings → Pages에서 Deploy from a branch를 선택하고 `main` 브랜치의 `/ (root)`를 저장하면 공개할 수 있습니다.

## 참고

- 공식 누리집: https://www.kead.or.kr/
- 글꼴: Google Fonts Noto Sans KR. 인터넷 연결이 없으면 시스템 글꼴을 사용합니다.
